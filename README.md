# LabBorrow · 实验室设备 RFID 借还登记系统

一套给高校实验室用的**设备借还自助登记程序**：同学刷一下贴在设备上的 RFID 标签即可借出/归还，
全程不用老师手工登记；支持校园卡识别身份、到期自动提醒（语音 / 界面 / **邮件**）、
自助终端模式（像闸机一样自己跑）、界面字号可调（照顾不同年龄和视力）。

- 运行环境：Windows 7 / 10 / 11，.NET Framework 4.0 及以上
- 数据存储：本机 SQLite 单文件数据库（**不联网也能完整使用**）
- 语言：C#（WinForms），无需安装 Visual Studio 即可编译

---

## 一、它能做什么

### 基础借还
- **刷标签即借出 / 归还**：把贴有 UHF 标签的设备靠近读写器，自动识别并显示设备名、型号、当前状态。
- **借用人身份**：可刷校园卡自动识别是哪位同学，也可手动选姓名/学号。
- **借用期限与临期判定**：借出时自动算出应归还时间；临期、逾期在界面上分色显示。
- **台账与记录**：设备台账（登记/编辑/停用）、借还流水、按人按设备的统计报表。
- **一键备份 / 恢复**：启动时自动备份（默认保留 10 份），可手动备份、从备份一键恢复。

### 四大改进（针对教学场景提出的需求）
1. **自动提醒归还（提醒对象是借用同学本人）**
   - 借出当场：借出框里写明「本次应归还：MM-DD HH:MM」，成功后语音念给本人听 + 屏幕大字显示；
     可打印一张「借条」交给同学带走（自助机接小票打印机即可自动出纸条）。
   - 他下次来刷卡（借还任意一件）：当面提醒他名下还有哪些快到期 / 已逾期。
   - 到期名单 →「生成催还消息」：按人分组，可直接复制到班级群 / 私聊 / 短信发给本人。
   - **自动发邮件**：借出即发「借用确认信」（写着归还日期），到期 / 逾期自动发「催还信」，
     一人一封、同一台设备按间隔最多一小时一封，不会骚扰。
2. **校园卡适配**：说明为何现在刷不了校园卡（见下文 FAQ），并支持 USB 免驱的 13.56MHz 读卡器。
3. **自助终端模式**：全屏无边框、触控大按钮、空闲自动回主控台、屏幕常亮、
   防随手关闭（Ctrl+Alt+Q 退出）、可开机自启 —— 放在实验室门口的小主机上就能自己跑。
4. **界面字号可调**：紧凑 / 标准 / 大 / 超大四档，另有「触屏友好」开关，切换后自动重启生效。

### 其它
- 防误刷 / 防刷单：连续命中确认、间隔保护、异常刷卡自动锁定。
- 读卡距离可调（调低射频功率，避免隔着墙刷到）。
- 提示音效可自定义（借出 / 归还 / 拦截 / 异常各一个音频文件）。

## 三、怎么运行

1. 进入 `LabBorrow_Release`，双击 **`LabBorrow.exe`**。
2. 第一次运行会自动在本机用户目录创建数据库，无需手工配置。
3. 连接 UHF 读写器（USB 口），在「系统设置 → ① 读卡距离」里点连接即可开始刷卡。

> 若提示数据库不可写或文件损坏，运行 `fix_integrity.bat` 修复；
> 需要换回旧数据用 `restore_database.bat`。

---

## 四、怎么编译（改代码后）

不需要安装 Visual Studio，Windows 自带 .NET Framework 编译器即可：

1. 改 `LabBorrow_Release\source\*.cs`；
2. 双击 **`rebuild.bat`**，它会：
   - 重新生成编译参数并编译出新的 `LabBorrow.exe`（旧程序自动备份为 `.bak`）；
   - 自动跑一遍**规则与数据层自测**；
   - 自动跑**界面冒烟测试**（把各页面渲染成截图，并体检设置项、分区展开、拖动窗口是否卡顿）。

编译产物与备份文件同样不会被提交到仓库。

## 五、常见问题

**Q：为什么刷不了校园卡？**
A：现有 UHF 读写器工作在 **860~960MHz**，读的是贴在设备上的 EPC 标签；
校园卡工作在 **13.56MHz**（Mifare / CPU 卡），两者频率、天线、协议都不同 ——
就像收音机收不到 WiFi，属于物理层面读不到，不是程序故障。
**解决办法**：买一个 USB 免驱的 13.56MHz 读卡器（PC/SC 读卡器，几十元即可），插上后
在「系统设置 → ⑪ 校园卡适配」里能看到读卡器列表并测试读号；
读到卡号后在「用户管理 → 刷卡建人」绑定给同学，之后刷校园卡即可识别身份完成借还。

**Q：没有网络能用吗？**
A：能。程序所有数据都在本机 SQLite 里，借还、台账、报表、语音提醒都不需要联网；
只有「自动发邮件」需要联网（发不出去也不影响借还功能）。

**Q：邮件提醒要用什么密码？**
A：不是邮箱登录密码。在邮箱网页版「设置 → 账户」里开启 SMTP 服务，
生成一个**授权码**填进去。授权码会用 Windows DPAPI 加密保存，数据库文件被拷走也解不开。

**Q：界面字太小 / 太大？**
A：「系统设置 → ⑧ 界面字号」选紧凑 / 标准 / 大 / 超大，保存后程序自动重启一次即可全界面生效。

## 六、隐私与安全

- 仓库**不包含**任何真实数据：数据库、备份、测试产物均已排除（见 `.gitignore`）。
- 同学的联系信息（手机号、邮箱）只保存在本机数据库中，不上传、不外发。
- 邮箱授权码经 Windows DPAPI 加密存储，仅当前电脑的当前用户可解密。
